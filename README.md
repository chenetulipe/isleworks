# Isleworks · L'île-usine

Jeu de gestion d'usine pour téléphone, jouable directement dans le navigateur.

Extrais des ressources, automatise tes lignes de production avec des tapis roulants,
agrandis ton île parcelle par parcelle et livre les vaisseaux qui passent.

- Jouable sur téléphone et ordinateur, en français et en anglais
- S'installe sur l'écran d'accueil comme une appli, et marche hors ligne
- Sauvegarde automatique dans le navigateur, aucune donnée collectée
